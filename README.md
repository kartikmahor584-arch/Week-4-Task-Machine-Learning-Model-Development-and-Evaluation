# Week 4 - Machine Learning Model Development and Evaluation

## Project
Breast Cancer Wisconsin (Diagnostic) classification with model comparison, cross-validation and hyperparameter tuning.

## Files
- `Week_4_ML_Model_Development.ipynb` - complete executed notebook
- `Week_4_ML_Report.pdf` - report aligned to the Week 4 evaluation criteria
- `Week_4_ML_Report.docx` - editable source of the report
- `requirements.txt` - Python environment dependencies
- `figures/` - report/notebook figures
- `model_comparison_cv.csv` - baseline 5-fold CV results
- `gridsearch_top10.csv` - top tuning configurations
- `test_predictions.csv` - holdout predictions
- `feature_coefficients.csv` - final model coefficients
- `results.json` - key metrics and best parameters

## Reproducibility
Run the notebook top-to-bottom with Python 3.11+ and the packages listed in `requirements.txt`.

## Dataset source
UCI Machine Learning Repository - Breast Cancer Wisconsin (Diagnostic):
https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
